# StatPrism User Guide

**StatPrism** is a desktop application for analyzing survey data and
producing publication-ready tables and figures. It is intended for researchers and
students who need correct statistics and APA-style output without writing code.

:::{admonition} Project links
:class: seealso

- **Website:** <https://www.yakovkinii.com/stat_prism/>
- **Video guides (YouTube):** <https://www.youtube.com/@statprism>
- **Video walkthrough:** <https://www.youtube.com/watch?v=_Od2_ckVa44>
- **Source code (GitHub):** <https://github.com/yakovkinii/stat_prism>
- **Downloads & releases:** <https://github.com/yakovkinii/stat_prism/releases>
