## How to cite

If you use StatPrism in your research, please cite it. A suggested format:

> Balashevych, O. K., Petrova, N. V., & Yakovkin, I. I. (2023). *StatPrism* (Version {{ release }})
> [Computer software]. https://doi.org/10.5281/zenodo.24532261

The repository also includes a machine-readable
[`CITATION.cff`](https://github.com/yakovkinii/stat_prism/blob/master/CITATION.cff) – GitHub
shows a **"Cite this repository"** button that generates APA/BibTeX from it.

```{note}
The DOI above is the **concept DOI**, which always resolves to the latest version. To cite the
exact version you used, take that version's own DOI from the
[Zenodo record](https://doi.org/10.5281/zenodo.24532261). Keep the year as 2023 (StatPrism's
first release) and set the version to the one you used.
```
