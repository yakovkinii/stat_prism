# Arrange Columns

Sets the dataset's column order by dragging every column into place in a single list &mdash; there
is no column selector.

- The list shows every column (except the **ID** column, which always stays first), each tinted with
  its color tag. Drag rows up or down to set the order; the rows are kept compact so a wide dataset
  fits with little scrolling.
- Columns added by a later step appear at the end until you move them.
- Only the column order changes; the values are untouched.
